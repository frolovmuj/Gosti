# Версия Богдана

Последний вариант сайта с анимациями и адаптацией под большие экраны и телефоны находится по адресу **`/concept-motion`**. Исходная главная страница `/` сохранена.

## Запуск

Из корня репозитория:

```powershell
cd frontend
corepack yarn install --immutable
corepack yarn dev
```

Открыть http://localhost:3000/concept-motion.

Для production-сборки из `frontend`:

```powershell
corepack yarn check
corepack yarn build
corepack yarn start
```

## Состав

- `frontend/app/concept-motion` — маршрут.
- `frontend/src/_pages/concept-motion` — интерфейс, анимации и локальный выбор блюд.
- `frontend/public/concept-pro/table.webp` — AI-иллюстрация первого экрана, созданная для предыдущего дизайнерского варианта и используемая в последней версии.
- Общие компоненты, фотографии меню и зависимости используются из существующего проекта.

Меню и цены демонстрационные. Выбор блюд хранится в браузере, реальные заказы не отправляются. Движение можно выключить кнопкой в верхней строке; системная настройка уменьшения движения учитывается автоматически. При наведении фотографии блюд увеличиваются без поворота.

Адаптация проверена в Chrome на ширинах от 320 до 2560 px, в том числе с эмуляцией touch и горизонтальной ориентации телефона. Физические iOS/Android-устройства отдельно не проверялись.
